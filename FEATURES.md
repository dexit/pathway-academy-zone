# FEATURES.md - Pathway Academy Zone

## Core Features
1. **Premium Centered Hero Architecture**: A unified design system for page headers using `bg-primary`, radial gradients, and backdrop-blur glassmorphism badges.
2. **Dynamic SEO Engine**: Custom `Seo.tsx` component that expands abbreviations (Alternative Provision, SEMH Support) and ensures high-impact local indexing.
3. **Structured Data Hub**: Centralized `src/lib/json-ld.ts` for automated schema generation across all programme and content pages.
4. **Accessible Terminology**: Site-wide enforcement of full descriptive titles, eliminating ambiguous shorthand (AP/PAZ).
5. **Staggered Motion Variants**: Standardized `framer-motion` animations for consistent, professional page entry effects.
